= Théorème de Bayes — Formulation mathématique complète
:toc:
:sectnums:

== Problème posé

On considère :

* un paramètre inconnu θ ∈ Θ
* des données observées D
* une incertitude sur θ avant observation

Objectif :

Déterminer, à partir d’un a priori et d’un modèle d’observation, la loi conditionnelle de θ sachant une réalisation des données D.

[NOTE]
--
∫_Θ signifie "Intégrale sur toutes les valeurs possibles de θ"
--

== Objets probabilistes fondamentaux

=== A priori

L’a priori est une loi de probabilité sur le paramètre θ :

----
p(θ)
----

Propriétés :

* p(θ) ≥ 0
* ∫_Θ p(θ) dθ = 1

Il représente l’information disponible avant l’observation des données.

=== Vraisemblance

La vraisemblance est définie comme :

----
p(D | θ)
----

Interprétation :

Probabilité d’observer les données D si le paramètre θ est fixé.

Remarque importante :

p(D | θ), considéré comme fonction de θ, n’est pas une loi de probabilité
(car elle ne s’intègre pas à 1 sur Θ).

==== Illustration formelle (cas Binomiale)

Considérons le cas suivant :

----
S | p ~ Binomiale(n, p)
----

Les données observées sont :

----
D = { S = k }
----

La vraisemblance associée est (par définition, voir fiche loi binomiale) :

----
p(D | p) = C(n, k) · p^k · (1 − p)^(n − k)
----

où p ∈ (0,1).

Considérons maintenant cette expression comme une fonction de p.
Calculons son intégrale sur l’espace des paramètres :

----
∫₀¹ C(n, k) · p^k · (1 − p)^(n − k) dp
----

Le coefficient binomial ne dépend pas de p et peut être factorisé :

----
C(n, k) · ∫₀¹ p^k · (1 − p)^(n − k) dp
----

On reconnaît l’intégrale définissant la fonction Bêta :

----
∫₀¹ p^k · (1 − p)^(n − k) dp = B(k + 1, n − k + 1)
----

On obtient donc :

----
∫₀¹ p(D | p) dp = C(n, k) · B(k + 1, n − k + 1)
----

Ce résultat :

- dépend des valeurs n et k,
- n’est pas égal à 1 en général,
- n’est pas une constante universelle indépendante des données.

Par conséquent, la vraisemblance, considérée comme fonction du paramètre p,
n’est pas normalisée sur l’intervalle (0,1).

Elle ne constitue donc pas une densité de probabilité sur l’espace des paramètres.


=== Postérieure

La postérieure est la loi de probabilité de θ après observation de D :

----
p(θ | D)
----

Elle doit satisfaire :

* p(θ | D) ≥ 0
* ∫_Θ p(θ | D) dθ = 1

== Théorème de Bayes (forme continue)

Le théorème de Bayes s’écrit :

----
p(θ | D) = (p(D | θ) · p(θ)) / (∫_Θ p(D | θ) · p(θ) dθ)
----

Cette égalité est une identité mathématique exacte.

== Rôle du dénominateur

Le terme :

----
∫_Θ p(D | θ) · p(θ) dθ
----

est appelé :

* probabilité marginale des données
* ou evidence

Propriétés :

* c’est une constante (ne dépend pas de θ)
* elle assure la normalisation de la postérieure
* elle garantit que p(θ | D) est une loi de probabilité

Sans ce terme, l’expression n’est pas une densité.

== Conjugaison Beta–Binomiale (démonstration complète)

On part strictement du théorème de Bayes, sous sa forme continue :

----
p(θ | D) = (p(D | θ) · p(θ)) / (∫_Θ p(D | θ) · p(θ) dθ)
----

Cette égalité est une identité mathématique exacte.

Dans ce qui suit, on montre que, sous certaines hypothèses explicites,
la loi postérieure appartient à la même famille que la loi a priori.

=== Hypothèses du modèle

On suppose :

* θ = p ∈ [0,1] est un paramètre inconnu
* S est une variable aléatoire comptant le nombre de succès
* n essais indépendants sont observés
* k succès sont observés (S = k)

=== A priori

On suppose que le paramètre inconnu p est une variable aléatoire
suivant une loi Bêta de paramètres (a, b) :

----
p ~ Beta(a, b)
----

avec :

- a > 0
- b > 0

La densité associée à cette loi est donnée par :

----
p(p) = 1 / B(a, b) · p^(a − 1) · (1 − p)^(b − 1)
----

où la fonction de normalisation B(a, b) est définie par :

----
B(a, b) = ∫₀¹ t^(a − 1) · (1 − t)^(b − 1) dt
----


=== Vraisemblance

Conditionnellement à p, la variable S suit une loi binomiale :

----
p(S = k | p) = C(n,k) · p^k · (1−p)^(n−k)
----

Cette expression est la vraisemblance du modèle.

Remarque fondamentale :

p(S = k | p), vu comme fonction de p, n’est pas une loi de probabilité.

=== Application directe du théorème de Bayes

La loi postérieure est :

----
p(p | S = k)
= (p(S = k | p) · p(p)) / (∫₀¹ p(S = k | p) · p(p) dp)
----

On remplace chaque terme par son expression explicite :

----
p(p | S = k)
= [C(n,k) · p^k · (1−p)^(n−k) · (1 / B(a,b)) · p^(a−1) · (1−p)^(b−1)]
  / ∫₀¹ [C(n,k) · p^k · (1−p)^(n−k) · (1 / B(a,b)) · p^(a−1) · (1−p)^(b−1)] dp
----

=== Simplification algébrique

Les constantes C(n,k) et 1/B(a,b) apparaissent au numérateur et au dénominateur ;
elles s’annulent.

Il reste :

----
p(p | S = k)
= [p^(k + a − 1) · (1−p)^(n − k + b − 1)]
  / ∫₀¹ p^(k + a − 1) · (1−p)^(n − k + b − 1) dp
----

=== Reconnaissance de la fonction Beta

Par définition, pour tout α > 0 et β > 0 :

----
B(α,β) = ∫₀¹ t^(α−1) · (1−t)^(β−1) dt
----

On identifie directement :

----
α = a + k
β = b + n − k
----

Donc le dénominateur vaut :

----
B(a + k, b + n − k)
----

La densité postérieure devient :

----
p(p | S = k)
= 1 / B(a + k, b + n − k)
  · p^(a + k − 1)
  · (1−p)^(b + n − k − 1)
----

=== Conclusion (conjugaison)

Par définition même de la loi Beta, on a :

----
p | (S = k) ~ Beta(a + k, b + n − k)
----

Cette propriété est une conséquence directe du théorème de Bayes
et de l’algèbre des puissances.

Aucune hypothèse supplémentaire n’est utilisée.

== Moments de la loi postérieure

Si :

----
p ~ Beta(a,b)
----

Alors :

----
p | D ~ Beta(α, β)
----

avec :

----
α = a + k
β = b + n − k
----

=== Espérance

----
E[p | D] = α / (α + β)
----

=== Variance

----
Var(p | D) = (αβ) / ((α + β)^2 · (α + β + 1))
----

Ces formules s’appliquent directement à la loi postérieure obtenue ci-dessus.

== Généralisation : autres lois conjuguées usuelles

Le schéma général est le suivant :

----
θ ~ A_priori(λ)
⇒
θ | D ~ A_posteriori(λ')
----

où les paramètres λ' sont obtenus par combinaison algébrique
de l’a priori et des statistiques suffisantes des données.

---

== Moyenne réelle inconnue — Normal / Normal

=== Hypothèses

- X_i | μ ~ Normal(μ, σ²), σ² connue
- μ ∈ ℝ inconnu

A priori :

----
μ ~ Normal(μ₀, τ₀²)
----

=== Loi postérieure

Après n observations de moyenne empirique X̄ :

----
μ | D ~ Normal(μₙ, τₙ²)
----

avec :

----
τₙ² = (1/τ₀² + n/σ²)⁻¹
μₙ = τₙ² · (μ₀/τ₀² + n·X̄/σ²)
----

=== Moments

----
E[μ | D] = μₙ
Var(μ | D) = τₙ²
----

---

== Variance inconnue — Inverse-Gamma

=== Hypothèses

- Observations normales
- Variance σ² inconnue, σ² > 0

A priori :

----
σ² ~ Inverse-Gamma(α, β)
----

=== Loi postérieure

Après n observations :

----
σ² | D ~ Inverse-Gamma(α + n/2, β + ½∑(xᵢ − μ)²)
----

=== Moments (si α > 2)

----
E[σ² | D] = β / (α − 1)
Var(σ² | D) = β² / ((α − 1)² (α − 2))
----

---

== Comptages — Poisson / Gamma

=== Hypothèses

- K_i | λ ~ Poisson(λ)
- λ > 0 inconnu

A priori :

----
λ ~ Gamma(α, β)
----

=== Loi postérieure

Après n périodes d’observation, avec S = ∑K_i :

----
λ | D ~ Gamma(α + S, β + n)
----

=== Moments

----
E[λ | D] = α / β
Var(λ | D) = α / β²
----

---

== Temps avant événement — Exponentielle / Gamma

=== Hypothèses

- T_i | λ ~ Exponentielle(λ)
- λ > 0 inconnu

A priori :

----
λ ~ Gamma(α, β)
----

=== Loi postérieure

Après observation de n temps, avec T = ∑T_i :

----
λ | D ~ Gamma(α + n, β + T)
----

=== Moments

----
E[λ | D] = α / β
Var(λ | D) = α / β²
----

---

== Cas non conjugués (ex. Weibull)

Pour certaines lois (ex. Weibull), il n’existe pas de conjugaison analytique simple.

Dans ces cas :

- la postérieure n’a pas de forme fermée
- les moments doivent être estimés numériquement
- on utilise Monte Carlo (MCMC), approximation ou quadrature

Le principe bayésien reste strictement identique.

---

== Synthèse conceptuelle

Bayes ne fournit pas une loi universelle.

Il fournit une règle de mise à jour :

----
A priori + données → postérieure
----

Les lois Beta, Normal, Gamma, Inverse-Gamma sont des outils adaptés
à des mécanismes d’observation différents.

Comprendre profondément un cas conjugué
revient à comprendre Bayes dans son essence.

== Lecture conceptuelle de la formule

Le théorème de Bayes combine :

* l’information préalable (a priori)
* le modèle d’observation (vraisemblance)

pour produire :

* une loi postérieure normalisée sur θ

Schéma conceptuel :

----
a priori + données → postérieure
----

== Résumé fondamental

Le théorème de Bayes est un opérateur mathématique qui transforme une loi
a priori sur un paramètre inconnu en une loi postérieure, à partir des
données observées, en conservant toute l’incertitude.
