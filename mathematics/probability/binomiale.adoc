= Loi binomiale
:toc:
:toclevels: 3
:sectnums:

== Idée centrale

La loi binomiale décrit le nombre de succès obtenus lors de n expériences
indépendantes de Bernoulli de même paramètre p.

Elle constitue le prolongement naturel de la loi de Bernoulli :

* Bernoulli : une observation binaire
* Binomiale : un comptage de succès

== Construction à partir de Bernoulli

Soient :

----
X₁, X₂, …, Xₙ
----

des variables aléatoires telles que :

* Xᵢ ~ Bernoulli(p)
* les variables X₁, …, Xₙ sont indépendantes

On définit la variable aléatoire :

----
S = Σᵢ Xᵢ
----

S représente le nombre total de succès observés sur n essais.

== Définition de la loi binomiale

On dit que S suit une loi binomiale de paramètres n et p, et on note :

----
S ~ Binomiale(n, p)
----

Lecture :
S « suit une loi binomiale de paramètres n et p ».

== Support de la loi binomiale

Puisque S est une somme de n variables qui ne prennent que les valeurs 0 ou 1 :

----
S ∈ {0, 1, 2, …, n}
----

== Fonction de masse de probabilité (PMF)

On cherche la probabilité d’obtenir exactement k succès sur n essais :

----
P(S = k)
----

=== Probabilité d’une configuration donnée

Considérons une suite particulière contenant exactement k succès et n − k échecs.

Par indépendance des observations :

----
P(cette suite) = p^k (1 − p)^(n − k)
----

=== Nombre de configurations possibles

Le nombre de suites distinctes contenant exactement k succès est donné par
le coefficient binomial :

----
C(n, k) = (n choose k)
----

qui compte le nombre de combinaisons possibles de k succès parmi n essais.

=== Loi de probabilité binomiale

En sommant sur toutes les configurations possibles, on obtient :

----
P(S = k) = C(n, k) · p^k · (1 − p)^(n − k),
k = 0, 1, …, n
----

Cette expression définit la loi binomiale.

== Espérance de la loi binomiale

Par linéarité de l’espérance :

----
E[S] = E[Σᵢ Xᵢ] = Σᵢ E[Xᵢ]
----

Or, pour chaque i :

----
E[Xᵢ] = p
----

Donc :

----
E[S] = np
----

Interprétation :
le nombre moyen de succès est égal au nombre d’essais multiplié
par la probabilité de succès.

== Variance de la loi binomiale

Par additivité de la variance pour des variables indépendantes :

----
Var(S) = Σᵢ Var(Xᵢ)
----

Or, pour une variable de Bernoulli :

----
Var(Xᵢ) = p(1 − p)
----

Donc :

----
Var(S) = np(1 − p)
----

== Interprétation statistique

* n : taille de l’échantillon
* p : probabilité de succès (paramètre inconnu)
* S : nombre de succès observés

La variable S est une *statistique suffisante* :
toute l’information contenue dans les observations
X₁, …, Xₙ est résumée par S.

== Hypothèses sous-jacentes

La loi binomiale repose sur trois hypothèses fondamentales :

* observations binaires (succès / échec)
* même probabilité de succès p pour chaque essai
* indépendance des observations

Si l’une de ces hypothèses est violée, la loi binomiale n’est plus adaptée.

== Lien avec l’inférence bayésienne

La loi binomiale joue un rôle central en statistique bayésienne.

Lorsqu’on considère p comme une variable aléatoire suivant une loi Beta,
la loi binomiale est conjuguée à la loi Beta.

Cette propriété permet une mise à jour analytique simple
des croyances sur p à partir des données observées.

== Conclusion intermédiaire

À ce stade :

* Bernoulli modélise une observation élémentaire
* la binomiale modélise un comptage de succès
* la somme des observations est la statistique pertinente
* le cadre est prêt pour introduire la loi Beta et Bayes

La prochaine étape logique est de transformer le paramètre p
en variable aléatoire et d’introduire la loi Beta.
